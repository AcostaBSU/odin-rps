# Odin Rock Paper Scissors

A simple JavaScript focused project where the user players Rock Paper Scissors against a computer as an intro project to learn the basics of JavaScript.

## Description

[Odin Rock Paper Scissors (Revisited)](https://www.theodinproject.com/lessons/foundations-revisiting-rock-paper-scissors) extends the [Odin Rock Paper Scissors ](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
design to give learners an opportunity to do hands-on JavaScript development with a focus on DOM manipulation and events by implementing an interactive UI. The project consists of an small HTML file with three buttons for each possible choice in a game of Rock Paper Scissors and a few additional elements for game updates. Additionally, the HTML file links an external JavaScript file to handle the user entry via buttons, carry out rounds of Rock Paper Scissors, and provide updates about the game until one player reaches a total of five rounds won. Afterwards, the web page pauses for 5 seconds and resets.
