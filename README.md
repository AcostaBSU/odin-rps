# Odin Rock Paper Scissors

A simple JavaScript only project where the user players Rock Paper Scissors against a computer as an intro project to learn the basics of JavaScript.

## Description

[Odin Rock Paper Scissors](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) is a project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
design to give learners an opportunity to do hands-on JavaScript development. The project merely consists of an HTML file to link an external JavaScript file which is where all of this project lives. After loading the JavaScript file, the user will be prompted to enter their choice in a game of Rock Paper Scissors for a total of five times. Subsequently, the game will conclude and determine if the game ends in a draw or with a declared victor. The game does assume the user will input with correct spelling and limit their entry to one of the following choices: rock, paper, or scissors
